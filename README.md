# ТРАКТ — демо-сайт грузоперевозок

Одностраничный сайт-демо для транспортной компании: калькулятор стоимости и срока доставки на схеме маршрутной сети, прозрачная раскладка цены, сравнение тарифов, отслеживание груза (демо), онлайн-заявка. Есть переключатель RU / EN. Все цены и цифры условные.

Сайт статический: HTML, Tailwind CSS (готовый `assets/css/styles.css` уже лежит в репозитории) и обычный JavaScript. Сервер, база данных и сборка для запуска не нужны.

## Как посмотреть у себя

Нужен только Python (или любой статический сервер). Из корня репозитория:

```bash
python -m http.server 5500
```

Откройте в браузере `http://localhost:5500/portfolio/demo-2/`. Просто двойной клик по `index.html` не подойдёт: браузер блокирует ES-модули с `file://`.

## Если правите стили

Нужен Node.js. В папке `portfolio/demo-2/`:

```bash
npm i
npm run watch:css   # пересборка CSS при правках src/input.css и index.html
npm run build:css   # одноразовая сборка (минифицированный styles.css)
npm test            # тесты расчёта цены, отслеживания и общих модулей
```

Собранный `assets/css/styles.css` нужно коммитить.

## Где что менять (без программиста)

| Что | Файл | Как |
|---|---|---|
| Тарифы, цены, опции, лимиты | `js/data/tariffs.js` | Меняете числа: ставка, минимум, скорость в сутки. Расчёт и таблицы подхватят сами. |
| Города и связи между ними | `js/data/cities.js` | Название на RU и EN, широта и долгота (для расстояния), положение на схеме `x` / `y`. |
| Цифры «Компания в цифрах» | `js/data/company.js` | Значения `value`; подписи — в `i18n/ru.js` и `i18n/en.js`. |
| Ваши данные в подвале | `js/data/author.js` | `name`, `telegram`, `url`. |
| Тексты сайта | `i18n/ru.js`, `i18n/en.js` | Каждая строка есть на обоих языках. |

### Отправка заявок

По умолчанию отправка имитируется: форма показывает номер заявки, но данные никуда не уходят. Чтобы заявки приходили к вам, откройте `js/data/author.js` и впишите адрес в `submitEndpoint`, например ссылку формы Formspree: `submitEndpoint: "https://formspree.io/f/xxxxxxx"`. Форма отправит туда JSON методом POST. Не кладите в этот файл секретные ключи: он виден всем посетителям.

## Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту-две демо будет доступно по адресу вида `https://<user>.github.io/<repo>/portfolio/demo-2/`. Все пути в проекте относительные, поэтому оно работает из подпапки.

## Что заменить перед публикацией

В репозитории стоит заглушка `https://example.github.io/portfolio`. Она нужна для ссылок и превью в соцсетях и мессенджерах. Её надо заменить на реальный адрес в двух местах. Правило: `siteUrl` + `/demo-2/` должно давать адрес, по которому открывается демо. Если вы публикуете, как описано выше, то `siteUrl` равен `https://<user>.github.io/<repo>/portfolio`. Если у вас другой адрес (свой домен, Vercel, отдельный репозиторий только для этого демо), подставьте его.

1. `js/data/author.js`, поле `siteUrl`.
2. `index.html`, в `<head>` две строки (теги `og:`):
   - `<meta property="og:url" content="https://example.github.io/portfolio/demo-2/">`
   - `<meta property="og:image" content="https://example.github.io/portfolio/demo-2/assets/img/og.png">`

Ссылка на картинку превью должна быть абсолютной (с `https://`), иначе соцсети её не покажут.

Заодно замените в `js/data/author.js` имя, Telegram и ссылку на свои.

## Превью-картинка

`assets/img/og.png` (1200×630) собрана из `og.html`, служебной страницы, на сайт она не ссылается. Если меняете оформление превью, поправьте `og.html` и снова сделайте снимок (из папки `portfolio/demo-2/`, Edge):

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --disable-gpu --hide-scrollbars --window-size=1200,630 --virtual-time-budget=5000 --screenshot="$(pwd -W)/assets/img/og.png" "file:///$(pwd -W)/og.html"
```

## Структура

```
index.html          страница
assets/             CSS (собранный), картинки, фавикон
src/input.css       исходные стили и дизайн-токены
js/data/            настройки: тарифы, города, цифры, автор
js/logic/           чистая логика: расстояние, цена, отслеживание
js/ui/              блоки интерфейса
js/lib/             общие модули: i18n, хранилище, формат, валидация
i18n/               тексты RU и EN
tests/              тесты (npm test)
```

Внешняя зависимость во время работы одна: шрифт Onest с Google Fonts.
